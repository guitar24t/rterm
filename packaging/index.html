rterm@VERSION@

Persistent terminal sessions that behave like a plain terminal. Packages for Ubuntu 24.04+, Debian, and RHEL 9 / Rocky / Alma (x86_64 and arm64), for macOS through Homebrew, and for Windows.

curl -fsSL @BASE_URL@/install.sh | sudo sh

The installer adds this signed repository to apt or dnf and installs rterm. From then on it updates with the rest of the system.

macOS

brew install guitar24t/tap/rterm

A universal binary for Apple Silicon and Intel Macs (macOS 11+). brew upgrade picks up new releases.

Windows

Download the .msi for your PC (x86_64 or aarch64) from the latest release and run it. It installs for your user only (no administrator rights) and adds rterm and rterm-connect to your PATH. The installer isn't code-signed yet, so SmartScreen may ask you to choose More info → Run anyway. To upgrade, run the newer MSI; running sessions keep running.

Ubuntu / Debian, by hand

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @BASE_URL@/rterm.gpg | sudo tee /etc/apt/keyrings/rterm.gpg > /dev/null
curl -fsSL @BASE_URL@/rterm.sources | sudo tee /etc/apt/sources.list.d/rterm.sources > /dev/null
sudo apt update && sudo apt install rterm

RHEL 9 / Rocky / Alma / Fedora, by hand

sudo curl -fsSLo /etc/yum.repos.d/rterm.repo @BASE_URL@/rpm/rterm.repo
sudo dnf install rterm

Picking a session from your laptop

rterm-connect lists the sessions on a host, lets you pick one or start a new one, and attaches over ssh. It also brings copies made by programs on the host (like Codex's copy-on-select) to your local clipboard, even in terminals that don't support that themselves, such as GNOME Terminal. It comes with every package above:

rterm-connect myserver

Or download just the script (Python 3.8+ and OpenSSH, nothing else):

curl -fsSLO @BASE_URL@/rterm-connect.py && chmod +x rterm-connect.py
./rterm-connect.py myserver

Automatic updates

apt upgrade and dnf upgrade pick up new releases. On Ubuntu, the installer also allows unattended-upgrades to update rterm (origin rterm); set RTERM_NO_AUTO_UPDATE=1 to skip that. On RHEL, enable dnf-automatic if you want unattended updates.

Upgrading never interrupts running sessions; sessions started before an upgrade stay attachable.
